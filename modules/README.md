# Modules

Modules are numbered by **topic sequence**, not by week (decision D7). Teaching weeks are assigned only in [`../course/schedule.md`](../course/schedule.md), so the calendar can shift without renaming anything. Each folder's README states its status, whether its lab is graded, objectives, lecture and lab plan, datasets with licence status, the old material it reuses or retires, and its assessment links.
