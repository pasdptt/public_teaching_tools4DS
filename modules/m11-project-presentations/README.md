## Objectives (draft; finalise when the module is produced)

By the end of this module a student can:

1. **Present** an end-to-end analysis with its evaluation design, results, limitations and failure analysis.
2. **Explain** any cell of the team's code when selected at random during the team's Q&A.
3. **Connect** the course's methods through their shared eigenproblems (PCA, LDA, spectral graphs, PageRank).

## Lecture (2 h per teaching week)

* Synthesis: eigenproblems across the course; when each method is (not) appropriate
* Final-examination preparation

## Lab (3 h per teaching week)

Live presentations: up to 20 teams × 15 min (8-minute talk + 6-minute Q&A in which **two randomly chosen members** explain code cells), across the 5 contact hours of one adjustment week.

**Failure analysis (required in every lab):** Each team reports one failure it found in its own analysis and the evidence for the fix.

## Independent work (5 h per teaching week)

Final revision (5 h).
